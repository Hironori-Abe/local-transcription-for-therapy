# Local Transcription for Therapy (LoTT) v0.9.8

臨床心理・カウンセリング会話のための、ローカル完結の日本語文字起こしデスクトップアプリです。
文字起こし・話者分離・文章校正を、会話データを PC の外へ送ることなく実行できます。

## ダウンロード

| ファイル | 対象 | 備考 |
| --- | --- | --- |
| `LoTT-v0.9.8-windows-x64-cuda-setup.exe` | NVIDIA GPU (CUDA 12.x) | 主配布・安定版 |
| `LoTT-v0.9.8-windows-x64-cpu-setup.exe` | GPU 不要 | 動作確認・試用向け（常用非推奨） |
| `LoTT-v0.9.8-windows-x64-editor-setup.exe` | GPU 不要 | JSONの読込・編集・書き出しに特化した軽量版（文字起こし・話者分離なし） |
| `SHA256SUMS.txt` | — | 各ファイルの SHA-256 チェックサム |

ダウンロード後の検証（任意）:

```sh
sha256sum -c SHA256SUMS.txt
```

## 変更点

### 話者分離後の句読点付与を自動化

- 句読点付与をユーザーが選んで実行する方式を廃止しました。
- Full GPU版では、話者分離の完了後に内蔵のGemma 4 E4BでAI句読点付与を自動実行します。設定でGemma 4 12BやローカルAIアプリを選択していても、自動句読点付与には既定のE4Bを使用します。
- CPU版では、話者分離の完了後にローカルルールによる単純な句読点付与を自動実行します。
- Editor版はJSONの読込・編集・書き出しに整理し、自動句読点付与と手動の句読点付与操作を搭載しません。
- 自動化に伴い、句読点付与方法の選択肢、実行ボタン、設定タブの句読点付与プロンプトUIを削除しました。

### 結果画面と設定画面のレイアウト改善

- 結果画面上部に重複していた校正説明・操作セクションを削除し、JSON出力、話者名の表示変更、結果表を中心とする構成に整理しました。発言の統合と全体校正は結果表の下に残しています。
- 話者名の表示設定を2列にし、入力欄の間隔と文字サイズを調整しました。
- 「計算方式」を文字起こし画面から設定タブへ移し、「対象言語」の左に配置しました。
- 「再試行の理由」を「音声調整」の右へ移し、文字起こし開始ボタンを左側へ整理しました。

### 12B全体校正のダウンロード導線を改善

- 「全体校正（with 12B）」を選んだ際にGemma 4 12Bが未導入なら、約7GBのダウンロードと所要時間について確認ダイアログを表示するようにしました。
- ダウンロードを承認すると、その画面からモデル取得を開始します。進捗と取得容量は全体校正ボタンの下と設定タブに表示されます。
- ダウンロード完了後は、選択していた12B全体校正を自動的に開始します。

### 音声再生操作の改善

- 連続再生のスナックバーが閉じられた後、ショートカットで再生を再開してもスナックバーが戻らない場合がある問題を修正しました。
- スナックバーの「停止」を「一時停止」へ変更しました。一時停止しても再生位置、対象行、連続再生の残りを保持し、`Ctrl+Shift+Space`で同じ位置から再開できます。
- 再生速度の選択肢がライトモードで見えにくい問題を修正し、黒文字・白背景で表示するようにしました。
- 各行の音声再生アイコンに「ループ再生」「連続再生」のツールチップを追加しました。

## 動作要件

### NVIDIA GPU 版

- Windows 10 / 11 (x64)
- NVIDIA GPU + CUDA Toolkit 12.x + cuDNN 9.x
- VRAM 8GB以上

### CPU 版

| 項目 | 最低要件 | 推奨要件 |
| --- | --- | --- |
| OS | Windows 10 / 11 64bit | Windows 11 64bit |
| CPU | AVX2対応、4コア / 8スレッド | 6コア / 12スレッド以上 |
| RAM | **16GB** | **24GB以上** |
| ディスク空き容量 | 約10GB | 約15GB以上 |
| GPU | 不要 | 不要 |

## インストールと初回セットアップ

1. 利用するエディションのインストーラーを実行します。
2. アプリを起動し、セットアップタブからPythonパッケージと必要なモデルをインストールします。
   - **初回セットアップ時のみインターネット接続が必要です**。
   - 話者分離モデルの取得にはHugging Faceトークンが必要です。
3. セットアップ完了後はオフラインで動作します。

> **SmartScreen について**: 本インストーラーはコード署名されていないため、初回実行時に
> Windows SmartScreen の警告が表示されることがあります。「詳細情報」→「実行」で続行できます。
> 配布元（本 GitHub Release）からダウンロードしたファイルか、SHA-256 で確認してください。

## プライバシー

- 本アプリ自身は通常運用時にインターネット上のサービスへ接続しません。
- 会話データ・音声データをPC外のAPIへ送信しません。
- 文字起こし、話者分離、校正、音声入力、区間聞き直しを含む推論はPC内で完結します。
- インターネット接続を使用するのは、初回セットアップや追加モデル・バックエンドの取得時だけです。
