# Local Transcription for Therapy (LoTT) v0.9.7

臨床心理・カウンセリング会話のための、ローカル完結の日本語文字起こしデスクトップアプリです。
文字起こし・話者分離・文章校正を、会話データを PC の外へ送ることなく実行できます。

## ダウンロード

| ファイル | 対象 | 備考 |
| --- | --- | --- |
| `LoTT-v0.9.7-windows-x64-cuda-setup.exe` | NVIDIA GPU (CUDA 12.x) | 主配布・安定版 |
| `LoTT-v0.9.7-windows-x64-cpu-setup.exe` | GPU 不要 | 動作確認・試用向け（常用非推奨） |
| `LoTT-v0.9.7-windows-x64-editor-setup.exe` | GPU 不要 | 校正・編集中心の軽量版（文字起こし・話者分離なし） |
| `SHA256SUMS.txt` | — | 各ファイルの SHA-256 チェックサム |

ダウンロード後の検証（任意）:

```sh
sha256sum -c SHA256SUMS.txt
```

## 変更点

### ショートカットキーの追加

文字起こし結果の編集画面で使えるショートカットキーを追加しました。編集欄に文字を入力している最中でも使えます。

| キー | 動作 |
| --- | --- |
| `Ctrl+Shift+Space` | 連続再生の再生 / 一時停止 |
| `Ctrl+Shift+A` | 5秒戻す |
| `Ctrl+Shift+D` | 5秒進める |
| `Ctrl+Shift+E` | 話者を次の選択肢へ切り替える |
| `Ctrl+Shift+M` | Gemma 4による音声入力の開始 / 停止 |

- `Ctrl+Shift+Space` で一時停止すると、停止した行の文章欄にカーソルが移り、末尾に置かれます。聞き取った内容をそのまま入力できます。
- `Ctrl+Shift+E` は未入力（`-`）を飛ばして、話者の選択肢を順に送ります。カーソルが文章欄にある場合はその行、それ以外は再生中の行が対象です。
- `Ctrl+Shift+M` はカーソルがある行（カーソルがない場合は再生中の行）で音声入力を開始し、録音中にもう一度押すと録音を停止します。必要なAIモデルが未導入の場合や、メモリ容量が利用条件を満たさない場合は画面下部に案内を表示します。
- 従来の `Ctrl+Shift+F`（検索・置換）はこれまでどおり使えます。

### 表示の改善

結果表の「内容」列見出しに出しているショートカットの案内を、5秒ごとに切り替えて全種類を順に表示するようにしました。

WordとExcelの書き出しボタンを、Wordを既定操作とする一つの分割ボタンにまとめました。右側の三角ボタンからExcel書き出しを選択できます。

### 編集操作の修正

- 文字起こし結果の文章編集で、`Ctrl+Z`による「元に戻す」と、`Ctrl+Y` / `Ctrl+Shift+Z`による「やり直す」が機能しない問題を修正しました。
- 編集履歴は文章欄ごとに管理します。日本語入力を含む連続した入力はまとめて戻し、元に戻した後で新たに入力した場合はやり直し履歴を破棄します。
- 仮想スクロールで表示行が入れ替わる場合や、AI候補、検索・置換、JSON読込などで文章が更新される場合の画面同期は従来どおり維持します。

## 動作要件

### NVIDIA GPU 版

- Windows 10 / 11 (x64)
- NVIDIA GPU + CUDA Toolkit 12.x + cuDNN 9.x
- VRAM 8GB以上

### CPU 版

| 項目 | 最低要件 | 推奨要件 |
| --- | --- | --- |
| OS | Windows 10 / 11 64bit | Windows 11 64bit |
| CPU | AVX2対応、4コア / 8スレッド | 6コア / 12スレッド以上 |
| RAM | **16GB** | **24GB以上** |
| ディスク空き容量 | 約10GB | 約15GB以上 |
| GPU | 不要 | 不要 |

## インストールと初回セットアップ

1. 利用するエディションのインストーラーを実行します。
2. アプリを起動し、セットアップタブからPythonパッケージと必要なモデルをインストールします。
   - **初回セットアップ時のみインターネット接続が必要です**。
   - 話者分離モデルの取得にはHugging Faceトークンが必要です。
3. セットアップ完了後はオフラインで動作します。

> **SmartScreen について**: 本インストーラーはコード署名されていないため、初回実行時に
> Windows SmartScreen の警告が表示されることがあります。「詳細情報」→「実行」で続行できます。
> 配布元（本 GitHub Release）からダウンロードしたファイルか、SHA-256 で確認してください。

## プライバシー

- 本アプリ自身は通常運用時にインターネット上のサービスへ接続しません。
- 会話データ・音声データをPC外のAPIへ送信しません。
- 文字起こし、話者分離、校正、音声入力、区間聞き直しを含む推論はPC内で完結します。
- インターネット接続を使用するのは、初回セットアップや追加モデル・バックエンドの取得時だけです。
