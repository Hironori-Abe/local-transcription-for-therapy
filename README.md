# Local Transcription for Therapy (LoTT)

**日本語** | [English](README.en.md)

臨床心理・カウンセリング会話の逐語録づくりを補助する、ローカル完結のデスクトップアプリケーションです。
音声ファイルから **文字起こし・話者分離・文章校正** までを、会話データを PC の外へ送ることなく実行します。

LoTT が目指すのは、全自動で完璧な逐語録を作ることではありません。アプリは「おおまかな下書き」を作り、それを人が音声を聞き返しながら仕上げることを想定しています。そのため、下書きを作る処理と同じくらい、聞き返しながら直す編集画面を重視しています。

![編集画面](docs/screenshots/transcript-ui.png)

## 特徴

- **完全ローカル実行** — 初回のモデル取得を除き、インターネット接続は不要です。会話・音声データを PC 外の API へ送信しません。AI（LLM）も使いません
- **文字起こし** — whisper.cpp（Whisper large-v3-turbo + Silero VAD）。NVIDIA / AMD / Intel の GPU を Vulkan で使い、GPU が無い PC では CPU で処理します。既定は日本語で、設定から24言語を選べます
- **話者分離** — NeMo-Speech.cpp + Nemotron-3-Diarization。結果は1文1行に分け、文ごとに話者を割り当てます（既定ラベル: Th / Cl / IP …）
- **文章校正** — フィラー・相づちを残した句読点付きの下書きを作り、氏名・地名など個人の特定につながりうる語を警告表示します（詳しくは下記「文章校正のしくみ」）
- **編集画面** — 行ごとの再生・ループ再生・連続再生、キーボードショートカット、句点での行の分割、マイクからの音声入力
- **保存形式** — Word（.docx）/ Excel（.xlsx）/ SRT字幕 / JSON。いずれも任意のパスワードで暗号化して保存できます（Word / Excel は Office 標準の暗号化、JSON / SRT は AES-256 暗号化 ZIP）。パスワード付きで保存するとき、暗号化されていない内容をディスクに書き出しません
- **軽い動作要件** — GPU で処理する場合、VRAM 6GB 以上を推奨します（実測の最大使用量は約1.9GB）

## 文章校正のしくみ

v0.9.9 で校正の方式を作り直しました。以前の Gemma 4 による AI 校正・全体校正は廃止し、AI（LLM）を使わない次の3段階で構成しています。

1. **句読点とフィラー（文字起こし時）** — 日本語では、句読点とフィラーを含む中立な例文を whisper.cpp に毎回渡します。Whisper がその書き方をまねるため、「えーと」「うん」などのフィラー・相づちを残したまま、句読点の付いた文が出力されます（計測では99%以上の行が句読点で終わりました）。例文には臨床的な内容や固有名詞を含めていません
2. **ローカルルールによる仕上げ** — 日本語直後の半角「?」「!」を全角にそろえ、句読点で終わらない行の末尾を補います。文の中身は書き換えません
3. **個人情報の注意喚起** — 氏名、氏名としても使われる地名、ローカルな地名などの候補を**赤字**で、「〜病院」「〜学校」「〜さん」など特定の名称が前に来やすい語を**黄色**で表示します。ある程度の誤検出を許容し、見落としを減らす方針です

日本語以外の言語を選んだ場合は、日本語の例文・句読点ルール・記号の全角化を適用しません（個人情報の注意喚起は行います）。

> 「頻出語・注目語」の指定はありません。whisper.cpp に語を渡すと、話されていない語（臨床用語など）が出力される誤認識が確認されたためです。

## プライバシーとオフライン方針

- 文字起こし・話者分離・校正・音声入力は、PC 内の whisper.cpp / NeMo-Speech.cpp とローカルのルールだけで完結します。インターネット上の API は呼びません。
- インターネット接続が必要なのは、初回セットアップ（モデル取得）と、Editor 版で音声入力パックを取得するときだけです。モデルは固定版を SHA-256 で検証して取得します。
- AI（LLM）による推論機能は持たないため、会話データを推論サーバーへ渡す経路はありません。
- 本アプリ自身は通常運用時に外部へ通信しません。Windows 版では WebView2 のクラッシュダンプや、本アプリ・音声エンジンの異常終了時の Windows エラー報告が Microsoft へ自動送信されないよう設定し、Linux 版ではコアダンプを無効にしています。ただし、OS・WebView ランタイム（WebView2）・GPU ドライバなどのシステム側コンポーネントが行う必須診断・更新確認等の通信までは、本アプリから完全には制御できません。組織として完全なオフライン運用を求める場合は、OS やファイアウォール側の設定（ネットワーク遮断、プロキシ制限など）を併用してください。
- 技術者でない方向けの説明は [プライバシー説明（非エンジニア向け）](docs/privacy-guide.md)、利用者自身で送信がないことを確かめる手順は [オフライン動作の確認手順](docs/offline-verification.md) を参照してください。

## エディション

| エディション | 内容 |
| --- | --- |
| **LoTT Full** | 主配布。文字起こし・話者分離・文章校正・音声入力のすべてを含みます。NVIDIA / AMD / Intel の GPU に1つのインストーラーで対応（Vulkan）し、GPU が無い PC では CPU で処理します（時間がかかります）。CUDA Toolkit・cuDNN・Python・Hugging Face トークンは不要です |
| LoTT Editor | 保存した JSON の読込・編集・書き出しに特化した軽量版。文字起こし・話者分離はありません。任意の音声入力パック（約1.6GB）を導入すると、CPU で動く音声入力を使えます |

配布ファイル名の `vulkan` が Full 版、`editor` が Editor 版です。NVIDIA の GPU でも Full 版（`vulkan`）を使います。

ビルド済みのインストーラーを配布するのは Windows 版です。Linux 版（`.deb` / AppImage）は、利用者自身がビルドして使うことを前提にしています（下記「Linux で使う場合」）。

## 動作環境

### Full 版

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10 / 11 64bit。Linux x86-64 は自分でビルドして使います（試験的） |
| GPU で処理する場合 | NVIDIA / AMD / Intel の GPU（**VRAM 6GB 以上を推奨**）と、Vulkan に対応した最新の GPU ドライバー |
| GPU が無い場合 | CPU で処理（下記の最低要件あり） |
| ディスク | アプリ本体に加えて、モデル用に約1.7GB |

- 必要な VRAM の根拠: RTX 4060 Laptop（Vulkan）での実測の最大使用量は、文字起こし 1,879MiB、話者分離 150MiB でした。11.7分と58分の音声で同じ値で、音声の長さでは増えません。文字起こしと話者分離は順に実行するため、同時に使うのは多い方だけです。画面表示や他のアプリが使う分、ドライバーや GPU の種類による差を見込んで、余裕をもって 6GB 以上を推奨しています。
- 内蔵 GPU（Intel Arc / AMD Radeon の iGPU など）でも動作します。単体 GPU より時間はかかります。
- GPU が複数ある PC では、内蔵 GPU 以外で VRAM が最大の GPU を自動で使います。設定タブの「音声エンジンの GPU」で変更できます。
- GPU ドライバーが入っていない・古い場合は、起動時のダイアログとバナーで導入・更新を案内します（Windows のみ）。
- Linux で GPU を使うには、ホストの Vulkan ローダー（Ubuntu / Debian では `libvulkan1`。`.deb` は自動で導入します）と、Mesa または NVIDIA の Vulkan ドライバーが必要です。どちらも無い場合は CPU で処理します（ローダーは同梱のフォールバックを使います）。

### GPU が無い PC で使う場合（CPU 処理）

Full 版は、Vulkan に対応した GPU が見つからない場合、自動的に CPU で処理します。**処理時間が長くなるため、日常的・継続的な利用には GPU を搭載した PC をお勧めします。** 少量の音声で動作や品質を確かめるお試し用途を想定しています。

| 項目 | 最低要件 |
| --- | --- |
| CPU | AVX2 対応、4コア / 8スレッド以上 |
| RAM | **16GB 以上** |

- GPU が使えない場合だけ、起動時に最低要件を確認します。満たさない場合は不足項目を表示して終了します。満たす場合も、CPU で処理する旨と処理時間の注意を毎回表示します。
- 処理時間の目安は音声時間の約1.5〜2.5倍です。CPU の性能や音声の内容によっては、さらに長くなります。
- RAM 16GB 未満はサポート対象外です。

### Editor 版

- Windows 10 / 11 64bit。Linux x86-64 は自分でビルドして使います（試験的）。GPU は不要です。
- 音声入力を使う場合は、音声入力パック用に約1.6GB の空き容量が必要です。

## インストールと初回セットアップ

1. [Releases](https://github.com/Hironori-Abe/local-transcription-for-therapy/releases) から Windows 用インストーラー（`LoTT-vX.Y.Z-windows-x64-{vulkan|editor}-setup.exe`）を入手して導入します。Linux の場合は、下記「Linux で使う場合」の手順でビルドした `.deb` / AppImage を導入します
2. **Full 版**: アプリを起動し、セットアップタブから文字起こしモデル（Whisper large-v3-turbo・Silero VAD、約1.6GB）と話者分離モデル（Nemotron-3-Diarization、約0.1GB）をダウンロードします（要インターネット接続）
   - Hugging Face のアカウントやトークンは不要です。中断した場合は、セットアップを再実行すると続きから取得します
   - Nemotron-3-Diarization のライセンスは NVIDIA OpenMDW-1.1 です。本文はセットアップ画面から確認できます
3. **Editor 版**: JSON の読込・編集・書き出しだけならモデルは不要です。音声入力を使う場合は、設定タブから「音声入力パック」をダウンロードします

モデル取得の後は、文字起こし・話者分離・校正をオフラインで使えます。

### Linux で使う場合

Linux 版は、利用者自身がビルドすることを基本にしています。ビルド済みの `.deb` / AppImage を Releases に載せることもありますが、毎回ではありません。また、Linux 実機での GPU 動作や各ディストリビューションでの動作は未検証で、試験的な位置づけです。

1. Docker を用意し、このリポジトリを取得します（ビルド時はインターネット接続が必要です）
2. Full 版は `bash scripts/build-appimage-docker.sh`、Editor 版は `bash scripts/build-appimage-docker.sh --editor` を実行します（Ubuntu 24.04 のコンテナ内でビルドします）
3. `dist/vX.Y.Z/` にできた `LoTT-vX.Y.Z-linux-x64-{vulkan|editor}.{deb,AppImage}` を導入します

詳しい手順と注意点は [docs/release-build-linux.md](docs/release-build-linux.md) を参照してください。

### v0.9.8 以前からの更新

- CUDA 版・AMD (ROCm) 版・CPU 版と、Gemma 4 などによる AI 校正・全体校正（LM Studio / Ollama 連携を含む）は廃止しました。どの GPU でも Full 版をお使いください。
- NVIDIA（CUDA）版からは、Full 版が上書きインストールされます。CPU 版・AMD 版は別アプリとして残るため、Windows の「インストールされているアプリ」からアンインストールしてください。
- 旧版が残したモデルやキャッシュ（Gemma 4、Python 環境など）は、設定タブの一覧から確認して削除できます。会話データではありません。
- 保存済みの JSON はそのまま読み込めます。

## 使い方

1. **文字起こし** — 文字起こしタブで音声ファイルを選び、話者数を確認して実行します。文字起こし・話者分離・句読点の仕上げまでが続けて行われます
   - 画面には、処理に使う GPU の名前（CPU の場合はその理由）が表示されます
   - 雑音の多い録音では「音声調整」（低域ノイズの処理・強いノイズの処理・音量拡大・全般的な改善）を選べます。調整は文字起こしに使う音声だけにかかります。良質な録音では、かえって精度が下がることがあります
2. **編集** — 音声を聞きながら、内容と話者を直します（話者ラベルの既定値: `SPEAKER_00 → Th`、`SPEAKER_01 → Cl`、`SPEAKER_02 → IP` など）
   - 行ごとのボタンで、その行のループ再生や、そこからの連続再生ができます。もう一度押すと一時停止、さらに押すと同じ位置から再開します
   - 各行のマイクボタンで最大15秒録音すると、whisper.cpp で文字起こしした候補を1件示します（Full 版は GPU があれば GPU、Editor 版は常に CPU）
   - 赤字・黄色の警告は、個人の特定につながりうる語の候補です。逐語録の用途に応じて伏せ字などに直してください
3. **保存** — Word / Excel / SRT字幕 / JSON 形式で保存します。後で編集を続ける場合は JSON で保存しておくと、Full 版・Editor 版のどちらでも読み込めます

### キーボードショートカット（編集画面）

| キー | 操作 |
| --- | --- |
| `Ctrl+Shift+Space` または `Ctrl+Shift+P` | 連続再生 / 一時停止 / 再開 |
| `Ctrl+Shift+A` / `Ctrl+Shift+D` | 5秒戻す / 5秒進める |
| `Ctrl+Shift+E` | 話者の切り替え |
| `Ctrl+Shift+M` | 音声入力 |

IME が `Ctrl+Shift+Space` を使う環境では `Ctrl+Shift+P` をお使いください。

表示テーマは、タブ行の左端のボタンで「システムに合わせる」（初期値）/ ライト / ダークを切り替えられます。選択内容は次回起動時にも引き継がれます。

## 対応言語

既定は日本語です。設定タブの「対象言語」で、次の24言語から選べます。自動検出は行いません。

日本語、英語、中国語、ヒンディー語、テルグ語、ベンガル語、カンナダ語、韓国語、アラビア語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語、ロシア語、ペルシア語、インドネシア語、トルコ語、ベトナム語、タイ語、ウルドゥー語、タミル語、マラーティー語、スワヒリ語

- 画面の表示、校正ルール、出力の書式は日本語の臨床・カウンセリング記録を前提にしています。句読点の仕上げとフィラーの扱いは、日本語でだけ評価しています。
- 話者分離モデルの公式資料で対応を確認できない言語には「話者分離非対応」と表示します。話者分離自体はすべての言語で実行しますが、日本語以外の精度は検証していません。

## 技術スタック

- デスクトップ: Tauri 2（Rust）/ フロントエンド: Angular 21 + Angular Material
- 文字起こし: whisper.cpp（Whisper large-v3-turbo・Silero VAD。Vulkan ビルドを同梱）
- 話者分離: NeMo-Speech.cpp + Nemotron-3-Diarization（Vulkan ビルドを同梱）
- 文章校正: Whisper への例文による句読点・フィラーの誘導と、Rust のローカルルール、固有名詞の注意喚起。LLM は使いません
- 音声デコード・音声調整: LGPL 構成の ffmpeg CLI
- Python は同梱・使用しません
